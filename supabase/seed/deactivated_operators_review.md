```json
"operator-slug": {
  "is_active": true,
  "categories": ["snow_sports"],
  "verified_at": "YYYY-MM-DD",
  "notes_internal": "manual reactivation — reason"
}
```

Then run `node supabase/seed/apply_operator_verified.mjs`.
